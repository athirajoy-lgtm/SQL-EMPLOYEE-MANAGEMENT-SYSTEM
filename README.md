# SQL Employee Management System

This project demonstrates SQL database creation, constraints, joins, aggregations, and query operations using MySQL.

Files Included:
- MYSQL EMPLOYEE MANAGEMENT SYSTEM.sql
- MySQL Assignment 1 – DDL Commands & Constraints.pdf
- MySQL Assignment 2 – Querying Data.pdf

Topics Covered:
- DDL Commands
- Constraints
- INSERT Statements
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- GROUP BY
- HAVING
- Aggregate Functions
